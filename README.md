# WelBewust — Transcription & Email-AI Cost Calculator

A single-page, self-contained cost model for a Google Cloud voice/email-AI pipeline:

- **Transcription** — Google Chirp speech-to-text, live (real-time) vs. batch (after the fact)
- **Email drafting** — Gemini 2.5 (Flash-Lite / Flash / Pro), compared side by side

All figures are editable in the page itself — no build step, no dependencies. Rates sourced from Google's official pricing pages, verified 7 July 2026.

Open `index.html` directly in a browser, or view it live via GitHub Pages (see the repo's **About** section for the link).
